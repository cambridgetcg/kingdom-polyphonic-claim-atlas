# Repository instructions

These instructions apply to the whole repository.

## Contract

Preserve `KINGDOM Polyphonic Claim Atlas: Truth Relations Phase 0` as a deterministic, zero-dependency, offline, static, synthetic producer. Its protocol is `kingdom.truth-relations/0.1`. It teaches and adversarially tests distinctions among expression, interpretation, claim, evidence, inference, narrative, institutional status, provenance, assessment, correction, and a declared synthetic world. It does not determine truth for a person, source, institution, story, live claim, or world.

The public handoff is exactly this immutable historical triplet:

- `public/truth/polyphonic-claim-atlas-2026-08-26.json`
- `public/truth/schemas/v0.1/public-snapshot.schema.json`
- `public/POLYPHONIC-CLAIM-ATLAS-v0.1.md`

Never add a mutable alias, HTML page, runtime, service, API, MCP tool, network request, live input, real person, real allegation, personal data, upload, account, form, score, ranking, recommendation, automated verdict, action, reward, penalty, reputation effect, or adapter to Zerone, KARMA, NEN, money, access, moderation, governance, or enforcement.

Keep every assessment attributed to the declared synthetic Phase-0 method, scoped to one fixture, and bounded to the declared fixture date. Never introduce a global truth status; truth, person, speaker, witness, source, story, institution, or trust score; liar classification; intent inference; hidden-reasoning inference; or any rule that promotes consensus, provenance, official status, signatures, hashes, protocol receipts, confidence, coherence, or repetition into truth.

## Frozen inputs and outputs

Inputs are exact bounded files at `data/config.json`, `data/fixtures.json`, and `guide/public-guide.md`. Predecessor records are versioned SHA-256 bindings only. They import no content, endorsement, currentness, authority, evidence, truth, or action permission.

The local build may atomically replace only the declared public triplet. Schema generation may write only the declared public schema path. Do not introduce clocks, randomness, locale-sensitive formatting, network calls, dependencies, undeclared generated files, symlinks, or output-path arguments.

## Editing and verification

- Use Node.js built-ins only; keep runtime and development dependencies absent.
- Keep the public schema on Draft 2020-12. Every object is closed and every property is required.
- Preserve fatal UTF-8 decoding, decoded duplicate-key rejection, prototype-key rejection, safe integers, structural bounds, symlink rejection, null-prototype canonicalisation, exact input and predecessor receipts, fixed output paths, full-output personal-shape and forbidden-field scans, and atomic write/rename behavior.
- Preserve all 24 synthetic adversarial fixtures and their typed non-equivalences. Any consolidation or replacement requires protocol review; the fixture count must never exceed 24.
- Do not initialise Git, publish, tag, freeze, release, deploy, or message external systems until explicit maintainer authorization and independent review.

Before presenting a release candidate, run:

```sh
npm test
npm run validate
npm run build
npm run build:check
npm run check
npm run overview
```

Then repeat the build and prove every generated byte is unchanged; verify there are no symlinks, undeclared public files, dependencies, network capabilities, or changes outside this repository.
